## 📐 BM25 计算公式参考

### 完整公式
```
score(D, Q) = Σ IDF(qi) × [ TF(qi,D) × (k1+1) / (TF(qi,D) + k1 × (1-b + b×|D|/avgdl)) ]
```

### 参数说明
- `k1 = 1.5`: 控制词频饱和度
- `b = 0.75`: 控制文档长度归一化程度
- `IDF(qi)`: 逆文档频率
- `TF(qi, D)`: 词qi在文档D中的频率
- `|D|`: 文档D的长度（词数）
- `avgdl`: 语料库中文档的平均长度

### IDF 公式（BM25+版本）
```
IDF(qi) = log((N - df + 0.5) / (df + 0.5))
```
- `N`: 总文档数
- `df`: 包含词qi的文档数

## 🔍 常见问题排查

### 问题1: 分数总是固定值（如0.69、1.38等）
**原因**: 使用了静态IDF值 `log(2.0)`  
**解决**: 确保调用了 `FullTextIndex::calculate_bm25()`

### 问题2: 分数为负数
**原因**: 当词太常见时（df > N/2），IDF可能为负  
**解决**: 标准BM25会设置IDF下限为0或使用修正公式

### 问题3: 所有文档分数相同
**原因**: 
- 可能没有正确统计TF
- 或者avgdl使用了固定值
**解决**: 检查 `FullTextIndex::add_document()` 是否正确统计词频

### 问题4: 分数与测评平台不一致
**可能原因**:
- 停用词列表不同
- 分词结果不同
- 浮点数精度差异
**解决**: 使用相同的cppjieba版本和停用词表

## 💡 Tips

1. **调试技巧**: 在 `FullTextIndex::calculate_bm25()` 中添加LOG输出，查看IDF和avgdl的值
2. **性能优化**: 确保全文索引在内存中，避免每次查询都重新分词
3. **精度问题**: BM25分数使用 `double` 计算，返回 `float` 可能有精度损失
